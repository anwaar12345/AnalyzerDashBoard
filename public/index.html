How It Works

  • Spreadsheets: read exactly

    Excel, CSV and JSON are read by code, so the numbers match your file. Best with a header row, a column of labels or dates, and number columns.

  • PDF, Word and images: read by AI

    Google Gemini finds the tables. You check and fix them on the review screen before the dashboard is built.

  • Private

    Files are read in memory and never stored. Documents are sent to Gemini to be read. Your last dashboard stays in this browser.

1

Move between screens

Use the menu on the left (on phones, the menu at the top). Each item opens its own screen. Your browser's back button works, and every screen has its own link you can share.

2

Upload your own file

Open Upload file and drop a spreadsheet, PDF, Word file or image. For documents you first review the numbers (fix cells, remove tables), then the dashboard is built.

3

Overview

The main figure and key metrics, compared with the previous period. When there are several periods, switch them with the buttons at the top.

4

Charts and lists

Pick a tab above a chart and hover a point or region for details. Sort lists by Largest or Fastest growing.

5

Reading the colours

Green = growth, red = decline or loss, pink = change that is neither good nor bad. YoY = vs the same period last year; cc = constant currency.

6

Check the source

Every figure comes from the source file. Hover Source at the bottom for notes, and double-check important numbers.
